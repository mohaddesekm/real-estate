# 🏠 Real Estate

A real estate web application built with **Next.js** as a learning project.

The goal of this project is to learn and practice the core concepts of **Next.js with the Pages Router** by building a real-world style application for browsing and managing property listings.

## 🔗 Live Demo

[Live Demo](https://real-estate-blue-theta.vercel.app/homes)

---

## ✨ Features

- 🏠 Display property listings
- 🔍 Search properties
- ↕️ Sort properties based on user selection
- 📄 Dynamic pagination for property listings
- 🏡 View individual property details
- 📱 Responsive layout
- 🎨 Font Awesome icons
- ⚡ Dynamic routing with Next.js
- 🚀 Deployed with Vercel

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mohaddesekm/real-estate.git
```

### 2. Navigate to the project

```bash
cd real-estate
```

### 3. Install dependencies

```bash
pnpm install
```

### 4. Start the development server

```bash
pnpm dev
```

Open your browser and visit:

```text
http://localhost:3000
```

---

## 📦 Build

To create a production build:

```bash
pnpm build
```

To start the production server:

```bash
pnpm start
```
